TRAVELMATE AI — static deployment folder

To publish and share with friends:
1. Open https://app.netlify.com/drop
2. Drag the whole travelmate-site folder (or the ZIP) onto the page.
3. Copy the generated https://....netlify.app URL and send that to friends.

This publishes the demo publicly. All booking, payment, map, notification, and chat data in this prototype is simulated. No live provider integrations or emergency calling are connected.
